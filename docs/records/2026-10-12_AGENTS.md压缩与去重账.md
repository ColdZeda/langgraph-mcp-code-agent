## 五、🔴 红线核验（本次最重要的证据）

改前改后**都是 25 条**。逐条核对，以下全部仍在：

`PER_TURN_RESET` / `TaskCancelled` 必须继承 `BaseException` / **停止 ≠ 拒绝** /
缺失 usage 不许静默按 0 / 压实必须明显小于单次输入 / WSL2 只是隔离执行环境不是安全沙箱 /
`CancelToken` 一次任务一个 / 预算终止 ≠ 验收未通过 / 终止说明不许写"见上方轨迹" /
停止检查必须在权限之前 / 权限判定必须在缓存查询之前 / `read_file` 豁免外置 /
`AgentState` 全通道覆盖校验 / 三条入口都必须接工具包装层 / 私有仓不公开。

**保留判据**（供以后压缩沿用）：

> 判据不是"这条重要吗"，而是 —— **"删掉这行之后，下一个 AI 会话会不会做错事？"**
> 会 ⇒ 留；不会 ⇒ 搬进 `docs/` 并留一行指针。
