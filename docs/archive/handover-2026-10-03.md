## 五、这个项目为什么存在（背景，原始动机）

它是"**把多 Agent 协作 + 工具层 + 权限闸门做成一个能真跑的本机助手**"的实践：
目标不是做一个产品，而是把 **Agent 编排 / MCP 工具层 / RAG 全链路 / 上下文工程 / 评估体系 / 安全与 HITL**
这几件事**各自做到可测量、可复现、可解释代价**。所以它的验收标准是"**有数字、有反例、有边界**"，
而不是"功能清单长"。定位、边界与部署取舍见 `AGENTS.md`（本机单用户；部署留给第二个项目）。
