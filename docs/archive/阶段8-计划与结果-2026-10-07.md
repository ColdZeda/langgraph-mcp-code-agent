## 一、这一阶段要解决什么

用**探索测试**（人工以真实使用姿态跑 12 道题）暴露的问题，驱动一轮**稳健性修复**。
前两题的现场账（`2026-10-07_探索测试第1-2轮与问题账.md`）归出 6 条根因：

| 编号 | 现象 | 根因 |
|---|---|---|
| R1 | 任务里的模板占位符没被替换，模型没说、直接到处翻文件猜 | 缺"模板未渲染"检测 |
| R2 | 目标不明确时也硬猜着做 | 缺提问原则（何时该先问一句） |
| R3 | 任务一旦开跑**停不下来**（只能关进程） | 没有停止开关、没有墙钟 |
| R4 | 原始 `wsl` 命令绕过 VM 工具 ⇒ 反复弹权限框（15 次） | 工具选择 + 权限粒度 |
| R5 | 终止时抛出一段英文报错 + 「验收未通过」 | 终止文案与终止原因不匹配 |
| R6 | 终止说明让人"看上方工具调用轨迹"，但历史回放里没有轨迹 | 指路指向不存在的东西 |

## 二、原计划（P0 → P3）

| 优先级 | 内容 | 验收标准（当时定的） |
|---|---|---|
| **P0** | 协作式停止 + 任务墙钟（15 分钟）+ 界面停止按钮 + 任务状态条 | 真机上点停止能停；状态条能看到步数/耗时/token；停止后**不**写新产物 |
| **P1** | 终止文案统一（中文、区分"停止"与"预算"）；§十五A 三条提问原则写进提示词 | 终止说明不再出现英文报错与「验收未通过」；提示词里带原则且不含花括号 |
| **P1.5** | 入口"模板未替换"检测（候选池 §十五B） | 命中就**只回问、不进图**（0 次模型/工具调用） |
| **P2** | token 预算放宽 + 三项阈值**按模型窗口自动算**（候选池 §十三①） | 给了窗口能算出阈值、没给回落默认；`.env` 覆盖仍然优先 |
| **P3（可选）** | 缓存命中显示 / 轨迹持久化+回放 / 减少弹框 | 有余力才做 |

## 三、实际结果

| 项 | 结果 |
|---|---|
| P0 | ✅ 落地 **+ 真机验收**（状态条、停止、弹框遮罩挡住停止按钮的 F1、卡片步数跨轮累积的 F2 均已修） |
| P1 | ✅ 落地（`_cancel_message` / `_budget_message` 共用一套尾部；R6 那句已删并有**AST 级**守卫；`CLARIFY_PRINCIPLES` 拼进两个 Executor 提示词）；顺手修了 F3（终止那轮的重跑不计次）与"重跑撞预算被包装成验收失败" |
| P1.5 | ✅ 落地（`utils/placeholder_guard.py`；入口 + 工具层两道口子）；**实现偏离候选池原文**：改成"形状 + 占位词"双条件、单花括号一律不管、留「按字面处理」逃生口（理由：照字面会误伤两道评估题） |
| P2 | ✅ 落地（`config.token_budgets()` 运行期按窗口算；模型可在注册表或 Web 面板声明窗口） |
| 收尾补记 | ✅ 比例 **15%/35% → 25%/50%**；`node` 下限 **30000 → 4000**（原下限会把 32k 窗口顶到窗口的 94%，方向是反的）；本机 `.env` 里显式钉死的三行**注释掉** |
| P3 | ⏸ **暂缓**（"还不是很有必要"），条目留在候选池 |
| C / D / E（结构化提问出口、循环与无进展检测） | ⏸ **等真实数据**（跑 12 题时的现场记录），与 P3 是两回事 |

**两处刻意偏离候选池的留痕**（都在修复账里）：
1. §十五B 的判据不能照字面做（会误伤 `E016` 的 JSON 例子与 `E029` 的 `<数字>`）；
2. §十三① 的 `TASK ≈ 60~70%（窗口）` 比当时的写死值还紧，与"预算放宽"的结论相反 ⇒
   任务级改用「窗口倍数 + 下限」（`max(50 万, 4×窗口)`）——它是**成本保险丝**，不是"能否塞进一次调用"。

## 四、口径声明（重要）

- **评估成绩 `single 30/30 · multi 30/30` 取自旧阈值口径**：压实 6000 / 单次输入 30000 / 任务 200000，
  且当时**还没有**"按模型窗口推导阈值"。改动后**没有重跑评估**（30 题都是短任务，阈值变化主要影响长任务），
  因此该成绩与今后的新口径**不可直接对比**。
- **窗口默认 128000 是兜底假设**，不是探测值：模型名与窗口没有可靠的离线映射，不猜；
  未声明的模型一律按 128k 算（保守方向），在界面里填了更准。
- **阈值三件套没有本项目自己的 A/B 实测**：比例的选取依据是两条间接证据（外置导致同类题 token 涨 7.3 倍；
  "人为限额版"比"只计量版"更贵且更低分）+ 旧文档的"长会话 12000~32000"建议区间。

## 五、还没做的（交接）

   清产物 + 重跑第 1、2 题 + 继续 3~12 由**使用者自己**安排（助手不接手）。
2. **P3** 三项（暂缓）。
3. **C / D / E** 等真实数据。

   要**连上限一起抬**，否则"按窗口算"会被上限卡回原地。
